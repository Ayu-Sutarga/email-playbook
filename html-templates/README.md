# HTML Templates

All templates are unbranded, mobile-friendly and built for pasting into an outreach or newsletter tool's HTML editor (I use Instantly).

| File | Best for | Weight |
|---|---|---|
| [`newsletter-light.html`](newsletter-light.html) | Regular updates that should feel personal | 🟢 Light |
| [`cta-card.html`](cta-card.html) | One announcement, one action | 🟢 Light |
| [`video-block.html`](video-block.html) | Dropping a video into any email | 🟢 Light |
| [`newsletter-full.html`](newsletter-full.html) | Quarterly highlights for opted-in subscribers | 🟡 Medium |
| [`event-promo.html`](event-promo.html) | Selling tickets to a masterclass or event | 🟡 Medium |

For cold outreach, use the light HTML in [`../cold-outreach/`](../cold-outreach/) instead. No images, one link.

### Before you send
1. Replace every `{{PLACEHOLDER}}`, then search the file for `{{` to catch leftovers
2. Swap the colours `#2B4C7E` and `#F4F1EC` for your brand
3. Use your tool's built-in unsubscribe link
4. Send a test to yourself and click every link

See [`../deliverability.md`](../deliverability.md) for the full checklist.
